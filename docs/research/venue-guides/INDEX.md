## Status definitions

- `NOT_STARTED`: 未調査
- `IN_PROGRESS`: 調査中
- `RESEARCHED`: 現地実用レベルまで調査済み。ただし直前確認項目あり
- `NEEDS_UPDATE`: 重要情報の鮮度または根拠が不足
- `VERIFIED`: 旅行直前の一次情報再確認まで完了
